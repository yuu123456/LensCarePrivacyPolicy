# LensCarePrivacyPolicy

LensCareアプリのプライバシーポリシーページ

## 概要

このリポジトリには、LensCareアプリのプライバシーポリシーが含まれており、GitHub Pagesで公開されています。

## 公開URL

GitHub Pagesが有効になると、以下のURLでアクセスできます：
- `https://yuu123456.github.io/LensCarePrivacyPolicy/`

## ファイル構成

- `index.html` - プライバシーポリシーページ（HTML版）
- `privacy-policy.md` - プライバシーポリシー（Markdown版）
- `_config.yml` - Jekyll設定ファイル
- `.github/workflows/pages.yml` - GitHub Pages デプロイワークフロー

## GitHub Pagesの設定

このリポジトリは、GitHub Actionsを使用して自動的にGitHub Pagesにデプロイされます。

### 初回セットアップ

1. リポジトリの Settings > Pages に移動
2. Source を "GitHub Actions" に設定
3. 変更をmainブランチにプッシュすると、自動的にデプロイされます

## 更新方法

プライバシーポリシーを更新する場合：

1. `index.html` または `privacy-policy.md` を編集
2. 変更をコミットしてmainブランチにプッシュ
3. GitHub Actionsが自動的に変更をデプロイします

## ライセンス

このプライバシーポリシーは LensCare アプリ専用です。
